# Allowed signers for OpenClaw upstream tags.
#
# Each line authorises one SSH public key to sign upstream release tags. The
# format is the one git expects via `gpg.ssh.allowedSignersFile`:
#
#     <principal> namespaces="git" <key-type> <key-base64> [comment]
#
# `bump-pin.sh` and `check-pin.sh` pass this file to `git verify-tag` via
# `-c gpg.ssh.allowedSignersFile=<this-file>`. Any tag at the pinned SHA
# must be signed by one of the keys below or the build refuses (override:
# ALLOW_UNSIGNED_PIN=1, accompanied by a SYNC_LOG note explaining why).
#
# Rotation procedure:
#   - Add a new key: append a new line, commit as
#     `security: rotate openclaw upstream signer key (<who>)`.
#   - Remove a compromised key: delete the line, commit with the same
#     message prefix. Do NOT rewrite history — past pins were verified
#     against the historical key set, and forensic re-verification of
#     old SYNC_LOG entries needs the key history to remain in git.
#   - Squash-merging this file is forbidden. PR review of every key
#     change is the entire defence; collapsing history hides a malicious
#     addition.
#
