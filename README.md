# ArmorClaw

A local-first AI agent with a real memory. macOS and Windows. Source available.

This is the v2 codebase. v1 was retired in May 2026.

- [docs/VISION.md](docs/VISION.md) — what we're building and why

- [docs/SECURITY.md](docs/SECURITY.md) — what we commit to and what we explicitly do not
- [docs/adr/](docs/adr/) — architecture decision records

## Quick start

```
pnpm install
pnpm -F @armorclaw/desktop dev
```
